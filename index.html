Kalender verbinden

Die App legt eine Kalenderdatei in deinem Repository ab und schreibt sie bei jeder Änderung neu. Dafür braucht sie einen Schlüssel, der nur auf diesem Gerät bleibt.

Schlüssel erstellen

  1. Öffne github.com → Fine-grained token
  2. Name: beliebig, z. B. „Fuhrpark“
  3. Expiration: möglichst lang wählen — läuft der Schlüssel ab, meldet die App das
  4. Repository access: Only select repositories → dieses Repository auswählen
  5. Permissions → Repository permissions → Contents auf Read and write
  6. Generate token, dann kopieren

Wird nur auf diesem Gerät gespeichert und nie in das Repository geschrieben.

Kalender abonnieren

Diese Adresse trägst du einmalig auf dem iPhone ein:

—

Auf dem iPhone

  1. Einstellungen → Kalender → Accounts
  2. Account hinzufügen → Andere
  3. Kalenderabo hinzufügen
  4. Adresse einsetzen → Weiter
  5. „Alarme entfernen“ ausgeschaltet lassen — sonst kommen keine Erinnerungen
  6. Sichern

Ab jetzt holt sich der Kalender Änderungen selbst. Neue Fahrzeuge, gelöschte Fahrzeuge und neue HU-Daten erscheinen von allein — meist innerhalb einer Stunde.
